# OS BaseCamp VMware 提交客户端 1.1.2 安装说明

本说明适用于 VMware 中的 Ubuntu 24.04 桌面环境。请按顺序完成校验、安装和安装结果确认，再开始使用客户端。

软件请去网盘链接下载：通过网盘分享的文件：OSBaseCamp_VMware v1.1.2 链接: https://pan.baidu.com/s/1qcFeuWX_RglZLMWoVUyMSQ?pwd=gdci 提取码: gdci 

## 1. 准备安装文件并进入所在目录

将以下两个文件放到 **Ubuntu 虚拟机内的同一个文件夹**：

- [os_basecamp_submission_client_1.1.2-VMware_all.deb](../os_basecamp_submission_client_1.1.2-VMware_all.deb)
- [os_basecamp_submission_client_1.1.2-VMware_all.deb.sha256](../os_basecamp_submission_client_1.1.2-VMware_all.deb.sha256)

**必须先进入安装包所在目录，再执行后面的校验和安装命令。** 可以在文件管理器中打开该文件夹，在空白处右键选择“在终端中打开”；也可以执行下面的命令，将示例路径替换为自己的实际路径：

```bash
cd "/实际的安装包目录"
```

以下命令均在 Ubuntu 虚拟机内、本人平时学习的普通用户终端中执行，当前账户需要能够使用 `sudo`。不要先切换到 root 账户。

## 2. 校验安装包

```bash
sha256sum -c os_basecamp_submission_client_1.1.2-VMware_all.deb.sha256
```

确认显示该安装包校验成功，例如：

```text
os_basecamp_submission_client_1.1.2-VMware_all.deb: OK
```

若提示找不到文件，检查当前目录和两个文件的名称；若校验失败，重新获取配套的安装包和校验文件。校验通过后再继续安装。

## 3. 安装客户端

```bash
sudo env OS_BASECAMP_USER="$(id -un)" apt install -y ./os_basecamp_submission_client_1.1.2-VMware_all.deb
```

如提示输入密码，请输入当前账户的 `sudo` 密码并按回车，输入时终端不会显示字符。等待安装完成；命令中的 `./` 表示使用当前目录中的安装包，请保留。

## 4. 确认安装结果

完成 SHA-256 校验和安装后，执行：

```bash
dpkg-query -W -f='${Version} ${Status}\n' os-basecamp-submission-client-vmware
```

显示以下结果，即表示 VMware 版 1.1.2 已正常安装：

```text
1.1.2 install ok installed
```

若版本或状态不同，或安装过程中出现报错，请保留完整错误信息并联系教师处理，再继续使用。

## 5. 安装后开始使用

首次安装完成后，保存文件并重新启动 Ubuntu，再登录安装时的同一普通用户账户，打开新的 Bash 终端开始实验。

1. 双击桌面的“登记与更正学生资料”，按教师名单填写完整学号和姓名，点击“保存”。
2. 正常进行实验，提交前保存源码。
3. 双击桌面的“提交实验”，核对身份并选择对应的 Lab。选择该 Lab 的根文件夹，例如 `lab1`，其中应同时包含 `kernel/` 和 `xv6-user/`。
4. 等待出现“提交成功，服务器已确认归档。”。仅看到本地 ZIP 文件，还不能证明已经提交成功。

登记和提交时使用本人普通用户账户，不加 `sudo`。后续关机或重启前，先提交本轮需要保留的实验过程并保存 ZIP。
